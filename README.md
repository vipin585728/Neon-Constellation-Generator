# Neon-Constellation-Generator
✨ Neon Constellation Generator

An interactive HTML5 Canvas particle animation that transforms your mouse or touch movement into a dynamic neon constellation of glowing particles and connecting lines.

Move your cursor around the screen and watch a colorful constellation emerge in real time. 🌌

🚀 Features

- ✨ Interactive neon particle system
- 🖱️ Mouse movement support
- 📱 Touch movement support for mobile devices
- 🌈 Continuously changing HSL colors
- 🔗 Dynamic connections between nearby particles
- 💫 Smooth particle fading and movement
- ⚡ Built using pure HTML, CSS & JavaScript
- 📦 No external libraries or dependencies

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API

🎮 How to Use

1. Clone this repository:

git clone https://github.com/YOUR-USERNAME/neon-constellation-generator.git

2. Open the project folder.
3. Open "index.html" in your browser.
4. Move your mouse across the screen or touch the screen on mobile.
5. Enjoy the neon constellation! 🌌

Neon-Constellation-Generator/

🧠 How It Works

The project uses the Canvas API to create and animate particles.

Whenever the user moves the mouse or finger:

- New particles are generated at the pointer position.
- Each particle receives a random size and velocity.
- Particles gradually become smaller and disappear.
- Nearby particles are connected with thin lines.
- The hue continuously changes to create the colorful neon effect.

This creates the appearance of a constantly evolving digital constellation.

🎨 Customization

You can easily experiment with:

- Particle size
- Particle speed
- Connection distance
- Particle lifetime
- Background opacity
- Color transition speed
- Number of particles generated per movement

Try modifying the JavaScript values to create your own visual style.
